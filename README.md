# Inventory and Sales Management System

A Python command-line application for managing products, tracking stock, recording sales, and viewing reports. This project uses object-oriented programming and JSON for data storage.

## Features

- Add, find, and display products
- Check and update stock after a sale
- Record sales and calculate total prices
- View inventory, sales, low-stock, and revenue reports
- Save and load data using JSON

## Technologies

- Python
- Object-oriented programming
- JSON

## How to Run

1. Open a terminal in the project folder.
2. Run:

   ```bash
   python main.py
   
3. Follow the menu instructions.
## Data Storage
Product and sales data are stored locally in a data.json file. The program loads the saved data when it starts.

## Project Structure
- main.py — runs the menu and connects the program sections
- products.py — contains the Product class
- Inventory.py — manages the product inventory
- sales.py — records sales
- reports.py — displays reports
- storage.py — saves and loads JSON data
